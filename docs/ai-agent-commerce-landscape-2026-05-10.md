# AI Agent Commerce Landscape(2026-05-10 cap stone)

5 provider の AI agent commerce 対応 + 4 protocol 比較 + dis-intermediation 4 段歴史 pattern + tsuji niche position 整理。 第 4 段「AI agent が経済取引する未来は来るか?」 question への fact 集約 anchor。

## 結論:既に始まっている、 ただし path 試行錯誤中

5 provider 全員参戦中、 4 protocol 並走、 Anthropic 既に物理証拠取得(186 deals / $4,000 / 1 週間)。 ただし OpenAI Instant Checkout 一度 killed fact = trial-error stage。

## 5 provider AI agent commerce 対応(2026-05 時点)

| provider | 対応 | 状態 |
|---|---|---|
| **OpenAI** | ACP(Agentic Commerce Protocol)+ ChatGPT Agent(Operator 統合 2026-02)+ Instant Checkout | **2026-03 Instant Checkout 一度 killed**(30 Shopify merchants のみ + 「flexibility 不足」)、 再起動中、 product discovery focus 移行 |
| **Anthropic** | Computer Use(2024-10 + Opus 4.6 / Sonnet 4.6 強化)+ Project Deal(2025-12)+ Finance Agents(2026-05) | **物理証拠あり**:Project Deal で AI agent が **186 deals / $4,000 / 1 週間**、 Opus seller +$2.68 / item 平均、 commercial platform 候補化(eBay / Craigslist 統合 candidate) |
| **Google** | AP2(Agent Payments Protocol)+ Project Mariner(2026-05-04 終了 → Gemini Agent + Chrome 統合)+ Gemini Enterprise Agent Platform | **60+ 組織参画**:Adyen / American Express / Coinbase / Mastercard / PayPal / Salesforce / ServiceNow / Etsy 等、 Mandates(暗号 sign 済 digital contract)form |
| **Microsoft** | Copilot Checkout(2026-01)+ Brand Agents(Shopify)+ catalog enrichment / store operations agents | PayPal + Shopify + Stripe integration、 retail / B2B 中心 |
| **Perplexity** | Buy with Pro(Pro 限定 → Black Friday 全 user 拡大)+ Snap to Shop + PayPal partnership(5,000+ merchants) | **Buy with Pro 導入後 shopping intent query 5x 増加**、 Free model(OpenAI charge との差別化) |

## 4 protocol 比較

| protocol | 特徴 | tsuji 整合 |
|---|---|---|
| **x402**(Coinbase 2025-10、 Linux Foundation 2026-03、 Cloudflare / AWS / Stripe / Shopify 参画)| open protocol、 stablecoin / USDC、 **individual supplier 友好的** | **◎ tsuji 採用済、 個人事業整合最強** |

## アプリ広告 architecture との構造同型(永井さま観察 2026-05-10)

| アプリ広告 | x402 経済 |
|---|---|
| **SSP**(媒体側、 広告枠 inventory)| **永井さま endpoint**(supplier 側、 知識 / 思想 / N=1 fact inventory)|
| **DSP**(広告主側、 予算 + ターゲティング)| **AI agent**(知識需要側、 query + budget)|
| **RTB / Ad Exchange**(auction protocol)| **x402 protocol**(payment auction、 fixed price form)|
| **Ad Server / Tracking / Attribution**(配信 + 計測)| **CDP facilitator + Analytics Engine**(settlement + 監視)|
| **DMP**(audience data)| **memory bank / context engineering**(supplier 側知識資産)|

つまり構造同型、 ただし「中抜き構造の disruption が次の階層で起きている」 歴史 pattern 一段進化。

## tsuji 空白象限(individual supplier knowledge layer)

5 provider 全員「物販 shopping commerce」 中心:

- OpenAI / Microsoft / Perplexity = 物販 shopping retail
- Google AP2 = enterprise / merchant 軸
- Anthropic = internal experiment + finance agents 軸

つまり **individual supplier knowledge layer = 空白象限**。 tsuji = この象限の早期 N=1 実装、 物販 shopping commerce と直接競合しない niche。

## 「事業成立性」 fact 集約

直接的 fact:

- **Anthropic Project Deal 186 deals / $4,000 / 1 週間**(internal 実験、 AI agent commerce 物理証拠 N=1)
- **Perplexity Buy with Pro 後 shopping intent query 5x 増加**(demand growth fact)
- **AP2 60+ 組織参画**(enterprise 投資 fact、 protocol layer 重要性 confirm)
- **OpenAI Instant Checkout 一度 killed**(2026-03、 trial-error stage 確認 = 「既に来ている、 ただし path 試行錯誤」 整合)

残不確定軸:

- 個人 supplier 経路の AI agent reach 量(5/16 routine 監視で trend 確定待ち)
- knowledge / service supplier 経路 vs 物販 shopping 経路 の AI agent demand 比率
- x402 protocol 内で個人 supplier の discovery 経路(現状 GitHub README + Zenn 末尾 paste のみ)

「来る」 ✅ 確定、 「永井さま niche に届くか」 が残る question(2 段判断)。

## tsuji 戦略的含意 3 軸

### 1. 業界知識 transferability

DSP / SSP / RTB / Ad Exchange / Ad Server architecture 知識(誰が誰に何を売る / 価格決定 mechanism / 計測 attribution / fraud 対策)が **そのまま x402 経済設計に転用可能**。 tsuji の industry-fact `affiliate-ad-pdm` topic はこの転用素材。

### 2. AEO/GEO コンサル接続

- 既存:SEO = 検索 algorithm 向け最適化 / DSP / SSP = RTB market 向け最適化
- AI 経済時代:AEO / GEO = AI 回答 engine 向け最適化 / x402 supplier endpoint = AI agent market 向け最適化

つまり **「AI agent 経済時代の SSP 設計コンサル」** = 永井さま固有 service candidate。 enterprise 大手企業(b 系 DSP / メディア buying / 計測 product)が AI agent commerce 早期参加したい時、 永井さま = N=1 supplier 側実装 + 業界 architecture 知識 = 高単価コンサル説得力 source。

### 3. 一人 ASP / 一人代理店 vision 接続深化

第 4 段 disruption = **個人 + AI agent 直結 = 中間業者不要**(directly DSP / SSP 等価 service を 1 人で提供可能)。 一人 ASP / 一人代理店 vision の core thesis(中抜き構造排除)が、 第 1-3 段 disruption の延長で実装可能 fact。 tsuji = この延長の物理証拠第 1 段。
