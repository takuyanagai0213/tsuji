# Cross-flow with other sub-projects

`~/.claude/rules/compound-holdings-data-flow.md` 整合、 永井ホールディングス 5 設計指針:

1. silo 化回避
2. 共通基盤累積
3. N=1 多媒体再利用
4. 思想 anchor cross-pollination
5. brand voice 整合維持

## 5 軸 cross-flow design

| flow 方向 | 内容 | Phase |
|---|---|---|
| **tsuji ← omamori** | LINE 11 年 + 一次情報コンテキストビジネス vision の経済 monetization layer | Phase 1+(omamori MVP 第 2 段以降と整合) |
| **tsuji ← harness_eng** | brand 物理証拠(Mac 半開き / 100 Skills / 33,999 memory)を経済資本に変換 | Phase 0(takuyanagai0213/README PR #2 で signal 化) |
| **tsuji → harness_eng** | x402 / agent economy 体験 = flagship 記事候補化 + 連載シリーズ追加軸 | Phase 0(本プロジェクト立ち上げ自体が記事候補) |
| **tsuji ← monopoly-source** | OneTag b 系業界知識 → 業務委託案件選定軸 | Phase 1+(案件 inbound 後) |
| **tsuji → 全子プロジェクト** | x402 micropayment infrastructure 内蔵化 = 各子プロジェクト endpoint 経済 monetization layer | Phase 3 |
